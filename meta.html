Under-Specified
Single-word genre tags, evaluative without descriptive content. Forces reliance on model prior distribution.
Goldilocks Zone
40-60 words distributed across GMIV formula. Precise timbral targeting without attribute collapse.
Over-Specified
Mutually exclusive requirements, excessive numerical precision, descriptor proliferation beyond 6-8 elements.
Flatline Pattern — Under-Specified
  • Genre: "Good music"
  • Vague mood descriptors
  • No instrument technique
  • High output variance
TREATMENT: Apply 3-layer descriptors (Source+Technique+Treatment). Add temporal anchors.
Clean Waveform — Optimal
  • Compound descriptors
  • Orthogonal coverage
  • 40-60 word count
  • Low output variance
STATUS: Specification density follows diminishing returns curve. Maintain current parameters.
Erratic Pattern — Over-Specified
  • "Exactly 117.3 BPM"
  • Contradictory parameters
  • 6+ simultaneous elements
  • Attribute collapse
TREATMENT: Identify 3-4 critical attributes. Hierarchical prioritization. Remove redundant descriptors.
Case Studies: Prompt Transformation
"Rock music, sad, guitar"
→
Under-Specified
Relies entirely on prior distribution. Output: Generic grunge or acoustic ballad? Unpredictable.
"1990s Midwest emo, jangly electric guitar with light overdrive, bittersweet nostalgia, mid-2000s warm production, male tenor vocal"
→
Optimal Specification
18 words. Subgenre granularity + technique + production context. Activated cluster: precise.
"Exactly 117.3 BPM, -14.2 LUFS, Mixolydian mode with Phrygian dominant substitution, sparse minimal arrangement with full orchestral instrumentation, precisely 3 guitars panned at 45° 90° and 135°"
→
Attribute Collapse
Mutually exclusive (sparse vs orchestral). Excessive precision. Model finds compromise → confused/generic output.
